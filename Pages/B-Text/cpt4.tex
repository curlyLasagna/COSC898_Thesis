\chapter{Landscape Pages}\label{chap:final}

Some tables and figures may fit better on a landscape-oriented page. When using a landscape page, the page numbers must be rotated so that they will appear in the correct orientation when the document is printed and bound. The following page is an example of a correctly numbered landscape page.

% the beginning of the landscape mode
\begin{landscapepage}
% any heading command with a * mark will not be counted into the table of contents, use this carefully
\section*{(Landscape Page Example)}
% content here
This content is in landscape mode, and the page number is rotated as well. Read the inline comments for details of how to enable the landscape mode.
\end{landscapepage}
% the end of the landscape mode
