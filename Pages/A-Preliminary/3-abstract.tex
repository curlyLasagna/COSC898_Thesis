For many students, configuring their machines for each course can act as a significant blocker to actual learning. An entire lecture period is often sacrificed to the manual and imperative installation of software and dependencies. Personal devices introduce unknown variables such as their operating systems, configuration, or hardware, resulting in an unnecessary research time sink.

I propose a solution that leverages LLMs to synthesize a nix environment. We first provide an instructor’s natural language description, then the LLM queries an mcp-nixos server to discover valid package names and configuration options from live data. The output is validated via nix evaluation commands, where the functional nature of nix provides a deterministic success or failure signal. In the event of a failure, the LLM uses the error trace as context to correct itself until a valid, reproducible environment is produced.
