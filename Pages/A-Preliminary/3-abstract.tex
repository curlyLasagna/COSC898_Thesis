Inconsistent computing environments introduce pervasive friction in computer science education, where instructional time is frequently lost to troubleshooting machine-specific dependency conflicts. This thesis presents an autonomous framework that leverages agentic large language models (LLMs) to synthesize reproducible, declarative development environments using Nix Flakes directly from coursework requirements and project codebases. To ensure reliable synthesis within the massive Nixpkgs ecosystem, the architecture couples domain-specific agent scaffolding with real-time Model Context Protocol (MCP) package discovery and closed-loop compiler verification. Empirical evaluations demonstrate that the pipeline reliably produces functional development shells, while clean OS replays across Linux containers and macOS virtual machines demonstrate robust cross-platform determinism and expose ambient host-state leakage that host-side validation masks. Furthermore, a user study evaluating student onboarding ergonomics reveals key operational trade-offs between initial bootstrap overhead and deterministic activation. Finally, this thesis examines security implications of using Nix, establishing practical recommendations for adopting declarative environment management in computer science curricula.
